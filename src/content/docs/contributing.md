---

We welcome contributions across SDKs, adapters, tooling, and docs.

## Ways to Help

- File issues and feature requests
- Implement adapters for new databases
- Expand SDK support and tests
- Improve documentation and examples

## Getting Started

1. Pick a repo from the JSONQL organization.
2. Check the open issues and proposals.
3. Submit a PR with a focused change.

If you’re not sure where to start, open an issue describing your idea.
