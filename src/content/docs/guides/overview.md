JSONQL is designed to make JSON the first-class query language for APIs and databases. This guide outlines the main concepts and how they fit together.

## Core Concepts

- **Schema-first**: define your data shape and capabilities once.
- **Query plans**: JSONQL queries compile to execution plans for supported backends.
- **Portable SDKs**: consistent developer experience across Go, TypeScript, Python, and Java.

## Typical Workflow

1. **Model** your entities and relationships.
2. **Describe** query capabilities and constraints.
3. **Execute** queries through the SDK and runtime adapters.
4. **Validate** outputs with the compliance suite.
